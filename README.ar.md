# Agent Room

**إنت أصلاً بتستخدم وكيلين برمجة بالذكاء الاصطناعي. Agent Room بيخلّيهم يشتغلوا مع بعض — وإنت اللي ماسك القرار.**

لو بتكتب كود مع Claude و Codex، إنت عارف الروتين: تحطّ المهمة في واحد، تنسخ ردّه للتاني "علشان يراجعه"، وتتوه مين اقترح إيه، وتفضل إنت الصمغ البشري بين شباكين شات — وعلى بُعد نسخة‑لصق غلط واحدة من إنك تسيب وكيل يعبث في الريبو الحقيقي بتاعك.

Agent Room بيحطّهم في أوضة واحدة بدل كده.

الوكيلين بياخدوا نفس الأدلة من مشروعك. واحد يقترح تغيير وينفّذه — بس جوّه **نسخة مؤقتة** من الريبو، مش الحقيقي أبدًا. والتاني يراجع النتيجة. إنت بتشوف الاقتراح، والمراجعة، وسطر واضح: "الجولة وقفت ليه وإيه اللي محتاجاه بعد كده" — وبعدين **إنت** اللي تقرر. مفيش حاجة بتلمس مشروعك، مفيش pull request بيتفتح، مفيش إيميل بيتبعت، غير لما تقول أوكي.

ومش شباكين شات جنب بعض. Agent Room بيتابع نسخ الاقتراحات، والوكلاء اتفقوا على إيه **فعلًا**، والشغل خلص ولا لسه مستني منك — علشان الجولة تخلص لأنها فعلًا اكتملت، مش لأن حد خلص كلام.

ونفس القاعدة على الموصّلات: قراءة GitHub أو Gmail أو Supabase بموافقة لكل جلسة، وأي حاجة **بتغيّر** حاجة بتستنى كاقتراح لحد ما توافق عليها.

### الجولة بتمشي إزاي

1. **تثق في مشروع.** مفيش حاجة بتتشارك مع الوكلاء قبل كده.
2. **بيشتغلوا من نفس الأدلة.** واحد ينفّذ على نسخة مؤقتة؛ والتاني يراجع النتيجة قراءة بس.
3. **بتوصلك بطاقة قرار** — الاقتراح، والمراجعة، والسبب إن الجولة وقفت، وإيه الخطوة الجاية.
4. **إنت تقرر.** ووقتها بس يحصل الـ commit أو الدمج أو الـ PR أو الإيميل أو الكتابة في قاعدة البيانات — والشجرة بتتفحّص للأسرار مرة أخيرة قبل ما تنزل.

> جرّبه بأمر واحد (بعد ما ينزل على npm): **`npx agent-room`** — بيفتح في المتصفح.

## تشغيل السيرفر المحلي

محتاج Node.js نسخة 22 أو أحدث. Agent Room بيشتغل كـ **سيرفر محلي (loopback)** ويفتح في متصفحك.

أسرع طريقة — من غير clone ولا build (بعد ما ينزل على npm):

```bash
npx agent-room
```

أو من نسخة سورس:

```bash
corepack enable
pnpm install --prod --frozen-lockfile --ignore-scripts
pnpm start
```

البورت الافتراضي **`http://127.0.0.1:3210`** — غيّره بـ `PORT` لو حبيت. لو شغّلته بـ `npx` الداتا بتتحفظ في `~/.agent-room`، ومن السورس بتتحفظ جوّه مجلد المشروع؛ في الحالتين تقدر تحدّدها بـ `AGENT_ROOM_RUNTIME_DIR`.

## الأدوات المطلوبة

Agent Room بيستخدم اشتراكاتك الموجودة في الأدوات دي — مش بيمرّرهم على أي سحابة بتاعته:

- **Claude Code** — متثبّت ومسجّل دخول.
- **Codex CLI** — متثبّت ومسجّل دخول.
- **Git** — باسم وإيميل متظبطين للمشاريع اللي هتنفّذ عليها.
- **GitHub CLI (`gh`)** — مسجّل دخول، بس لو هتتصفّح GitHub أو تفتح issues/PRs.

لو مزوّد متثبّت كـ shim بس (زي Codex على ويندوز)، Agent Room بيكتشف الملف التنفيذي الأصلي ويوثّقه تلقائيًا. أي مسار إنت بتدّيه بنفسك بيتوثّق بس بعد ما توافق من **Trust & check**.

## الأمان باختصار

- مفيش حاجة بتتشارك مع الوكلاء قبل ما توثّق بصمة المشروع.
- التخطيط والمراجعة قراءة بس. بيئات الوكلاء بتستخدم allowlist ومبتورّثش مفاتيح عشوائية.
- كل تنفيذ في نسخة مؤقتة بأوبجكتس Git خاصة بيها، فالأوبجكتس المرفوضة أو اللي فيها أسرار مبتدخلش الريبو الأصلي.
- مفيش وضع تنفيذ "كامل" ولا نشر مسبق الموافقة. الـ PR بيتفتح بس من نقطة القبول.

للنموذج الأمني الكامل وطريقة الإبلاغ عن ثغرة، شوف [SECURITY.md](SECURITY.md).
